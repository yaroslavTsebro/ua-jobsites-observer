# Job Observer

Расширение Chrome по таймеру обновляет **уже открытые** вкладки со списками вакансий,
вытаскивает вакансии и отправляет на локальный сервер. Сервер шлёт в Telegram
только **новые вакансии за сегодня** (каждую один раз).

Сайты: djinni, jobs.dou.ua, work.ua, robota.ua, jobico, web3.career, LinkedIn.

## Запуск

1. `.env` (пример в `.env.example`): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
   Чтобы узнать chat id — напиши боту любое сообщение и выполни `npm run chat-id`.
2. Сервер: `npm start` (http://localhost:3777). Должен работать, пока работает браузер.
3. Расширение: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `extension/`.
4. Открой вкладки из `site-urls.txt` (и залогинься где нужно). В попапе расширения:
   «Тест Telegram», «Проверить сейчас», интервал (по умолчанию 15 мин).

## Как решается «сегодня»

- Дата берётся со страницы: djinni — тултип `HH:MM DD.MM.YYYY` (это время последнего
  обновления вакансии), DOU — «11 жовтня», web3 — `<time datetime>`, остальные — текст
  вида «2 години тому», «сьогодні», «3 hours ago».
- Если дату распознать не удалось, вакансия считается новой, если её не было на этой
  вкладке при прошлых проверках (первый проход по вкладке ничего такого не шлёт).
- Уже отправленные/увиденные вакансии хранятся в `data/state.json` (45 дней).

## Вкл/выкл

Кнопка вверху попапа или в Telegram: `/status` (кнопки под сообщением), `/on`, `/off`.
Выключено = автопроверки по таймеру не идут; «Проверить сейчас» и «🧪 Тест» работают всегда.

## Безопасный режим (чтобы сайты не считали это ботом)

- обычный reload вкладки в твоём браузере, без флагов автоматизации;
- интервал с разбросом ±20%, вкладки в случайном порядке, пауза 3–9 с между ними;
- LinkedIn — не чаще раза в 30 мин;
- вкладку, на которую ты сейчас смотришь, не трогает.

## Тесты

`npm run e2e` — настоящий Chrome (Chrome for Testing) + расширение + сервер, фейковый Telegram.
К сайтам не уходит **ни одного** запроса: страницы отдаются из `tests/fixtures` и `data/snapshots`
через перехват, всё остальное блокируется. Снимки своих вкладок — кнопка «📸 Снимок» в попапе
(вкладки при этом не перезагружаются).

## Если сайт перестал парситься

Селекторы — в `extension/extract.js`, массив `SITES`. После правки нажми «обновить»
у расширения в `chrome://extensions`.
