# Job Observer

Следит за вакансиями на нескольких сайтах и присылает в Telegram **только новые вакансии за сегодня**, каждую один раз.

Работает в твоём обычном Chrome: расширение время от времени обновляет уже открытые вкладки с поиском вакансий, вытаскивает со страницы список и отправляет его на маленький локальный сервер. Сервер решает, что новое, и пишет в Telegram-бота.

Поддерживаемые сайты: **djinni.co**, **jobs.dou.ua**, **work.ua**, **robota.ua**, **jobico.io**, **web3.career**, **LinkedIn**.

```
 Chrome (твои вкладки, твои логины)          localhost:3777                 Telegram
┌──────────────────────────────┐        ┌────────────────────┐        ┌──────────────────┐
│ расширение Job Observer       │  POST  │ server/server.js   │  API   │ твой бот         │
│ • раз в ~15 мин обновляет     │ ─────▶ │ • что уже было     │ ─────▶ │ 🆕 вакансия      │
│   вкладки со списками         │ /jobs  │ • что сегодняшнее  │        │ [👀] [✅] [👎]   │
│ • парсит вакансии             │ ◀───── │ • вкл/выкл, счётчик│ ◀───── │ /status /on /off │
└──────────────────────────────┘        └────────────────────┘        └──────────────────┘
```

## Что понадобится

- **Windows / macOS / Linux** с **Google Chrome** (или другим Chromium-браузером: Edge, Brave).
- **Node.js 20.6+** — https://nodejs.org (проверить: `node -v`).
- **Telegram** и 2 минуты, чтобы создать бота.

## Установка

### 1. Скачать проект

```bash
git clone https://github.com/yaroslavTsebro/ua-jobsites-observer.git
cd ua-jobsites-observer
```

Для работы ставить зависимости не нужно — сервер на чистом Node.js. `npm install` нужен только для тестов (скачает Chrome for Testing, ~150 МБ).

### 2. Создать Telegram-бота

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен кончаться на `bot`).
2. BotFather пришлёт токен вида `1234567890:AAH...` — это и есть `TELEGRAM_BOT_TOKEN`.
3. Найди своего бота по username и напиши ему что угодно (например, `/start`) — без этого бот не сможет тебе писать.

### 3. Настроить `.env`

Скопируй пример и вставь токен:

```bash
cp .env.example .env        # Windows (cmd): copy .env.example .env
```

```env
TELEGRAM_BOT_TOKEN=1234567890:AAH...
TELEGRAM_CHAT_ID=
PORT=3777
```

Узнай свой chat id (сервер в этот момент должен быть **выключен**):

```bash
npm run chat-id
# TELEGRAM_CHAT_ID=123456789   (твой_ник)
```

Впиши число в `.env`.

> `.env` в `.gitignore` — токен не попадёт в git. Если токен всё-таки утёк, выпусти новый: @BotFather → `/revoke`.

### 4. Запустить сервер

```bash
npm start
```

```
Job Observer server: http://localhost:3777
Мониторинг: включён
```

Сервер должен работать всё время, пока ты хочешь получать уведомления. Окно терминала можно свернуть, но не закрывать.

### 5. Установить расширение

1. Открой `chrome://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. **«Загрузить распакованное расширение»** → выбери папку **`extension`** внутри проекта.
4. Закрепи значок: пазл 🧩 справа от адресной строки → 📌 рядом с Job Observer.

### 6. Открыть вкладки с поиском

Открой страницы со списками вакансий с нужными тебе фильтрами — например, из `site-urls.txt`. Где нужно (LinkedIn, Djinni) — залогинься. Расширение работает только с **открытыми** вкладками, сами по себе ссылки оно не открывает.

Распознаются как списки:

| Сайт | Пример страницы |
|---|---|
| djinni.co | `https://djinni.co/jobs/?primary_keyword=Node.js` |
| jobs.dou.ua | `https://jobs.dou.ua/vacancies/?category=Node.js` |
| work.ua | `https://www.work.ua/jobs-node.js/` |
| robota.ua | `https://robota.ua/zapros/javascript/ukraine` |
| jobico.io | `https://www.jobico.io/en/jobs?search=node.js` |
| web3.career | `https://web3.career/javascript-jobs` |
| LinkedIn | `https://www.linkedin.com/jobs/search-results/?keywords=node.js` |

Страница отдельной вакансии не трогается.

### 7. Проверить, что всё работает

Нажми на значок Job Observer → **«🧪 Тест»**. Вкладки по очереди обновятся, а в Telegram придёт по одной (самой свежей) вакансии с каждой вкладки — независимо от даты. Если у какой-то вкладки «найдено: 0» — парсер для неё сломан (см. [Если сайт перестал парситься](#если-сайт-перестал-парситься)).

Готово. Дальше всё происходит само.

## Как пользоваться

### Попап расширения

| Элемент | Что делает |
|---|---|
| 🟢 **Мониторинг включён / ⏸ выключен** | Переключатель. Выключено = автопроверки по таймеру не идут. |
| 📬 **Непрочитанных в TG: N** | Вакансии, по которым ты ещё не нажал кнопку в Telegram. Кликни — раскроется список, клик по вакансии откроет её во вкладке. |
| **Интервал, мин** | Как часто проверять (по умолчанию 15). Нажми «Сохранить». |
| **Проверить сейчас** | Внеочередная проверка всех вкладок. |
| **🧪 Тест** | Шлёт в TG самую свежую вакансию с каждой вкладки (не влияет на «что уже было»). |
| **📸 Снимок** | Сохраняет текущие страницы в `data/snapshots` для офлайн-тестов. Вкладки **не** перезагружаются. |
| **Лог** | Что проверено, сколько найдено, ошибки. Новые вакансии — зелёные строки. |

Значок расширения:
- **красная цифра** — сколько непрочитанных вакансий;
- **OFF** — мониторинг выключен;
- **?** — сервер не запущен.

### Telegram

Каждая новая вакансия приходит отдельным сообщением:

```
🆕 Middle Node.js Developer
https://jobs.dou.ua/companies/acme/vacancies/123456/
dou · Acme · 2 години тому
[👀 Просмотрел] [✅ Аплай] [👎 Не то]
```

- Любая кнопка убирает вакансию из непрочитанных. Нажатая помечается ✓, выбор можно поменять.
- `/status` — включён ли мониторинг, когда была последняя проверка, сводка (непрочитанные / просмотрено / аплай / не то) и кнопка вкл/выкл.
- `/on`, `/off` — включить / выключить мониторинг.

Бот отвечает только на сообщения из чата `TELEGRAM_CHAT_ID`.

### Что считается «новой вакансией за сегодня»

- Дата берётся со страницы: точное время (djinni, web3, work.ua), «11 жовтня» (DOU), «2 години тому» / «вчора» / «3 hours ago» (robota.ua, jobico, LinkedIn).
- Вакансия отправляется, если её дата — **сегодня** и она ещё не отправлялась.
- Если дату распознать не удалось — вакансия отправляется, только если её не было на этой вкладке при прошлых проверках. При самой первой проверке вкладки такие вакансии просто запоминаются, чтобы не завалить чат всем списком.
- Одна и та же вакансия на нескольких вкладках приходит один раз. Одна вакансия на **разных сайтах** — это разные ссылки, придёт с каждого.
- На djinni видна дата последнего **обновления** вакансии — старая вакансия, обновлённая сегодня, тоже придёт.
- Память хранится в `data/state.json` 45 дней и переживает перезапуск.

### Как не получить бан

Расширение ведёт себя как человек, который иногда жмёт F5:

- обычная перезагрузка вкладки в твоём браузере, с твоими куками, без флагов автоматизации;
- интервал с разбросом ±20%, вкладки в случайном порядке, пауза 3–9 с между ними;
- **LinkedIn — не чаще раза в 30 минут**;
- вкладку, на которую ты сейчас смотришь, не перезагружает.

Не ставь интервал меньше 10 минут.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| В логе «Сервер … недоступен» / на значке **?** | Запусти `npm start`. После перезагрузки компьютера сервер нужно запускать заново. |
| «Нет открытых вкладок со списками вакансий» | Открой страницы поиска (таблица выше). URL отдельной вакансии не подходит. |
| «Пропущена (не страница списка)» | Вкладка на сайте из списка, но это не поиск — так и задумано. |
| У вкладки «найдено вакансий: 0» | Сайт поменял вёрстку или нужен логин. Открой вкладку и проверь, видны ли вакансии. Дальше — следующий раздел. |
| «Пропущена: ты сейчас на этой вкладке» | Так задумано: переключись на другую вкладку. |
| В Telegram ничего не приходит | Нажми «🧪 Тест». Если и он не приходит — проверь `.env` и что ты писал боту. Ошибки Telegram видны в терминале сервера. |
| `npm run chat-id` пишет «Нет сообщений» | Останови сервер (он забирает сообщения бота), напиши боту и запусти снова. |
| Изменил код расширения — ничего не поменялось | `chrome://extensions` → ⟳ на карточке Job Observer. |

## Если сайт перестал парситься

1. В попапе нажми **📸 Снимок** — страницы сохранятся в `data/snapshots/`.
2. `node tests/check-inject.mjs` — за пару секунд покажет, на каких страницах парсер не находит вакансии.
3. Селекторы для каждого сайта — в `extension/extract.js`, массив `SITES`:
   `item` — карточка, `link` — ссылка на вакансию, `title` / `company` / `date` — поля внутри карточки.
4. После правки: ⟳ у расширения в `chrome://extensions`, затем «🧪 Тест».

Новый сайт добавляется так же: запись в `SITES` (`extract.js`), шаблон URL списка в `LIST_PAGES` (`background.js`) и домен в `host_permissions` (`manifest.json`).

## Тесты

```bash
npm install          # один раз: puppeteer + Chrome for Testing, jsdom
npm run e2e          # ~15 мин
```

Запускает **отдельный** Chrome for Testing с расширением, настоящий сервер (на порту 3902, во временной папке) и фейковый Telegram. Страницы отдаются из `tests/fixtures/` и `data/snapshots/` через перехват запросов, всё остальное блокируется — **к сайтам не уходит ни одного запроса**, твой рабочий сервер и `data/state.json` не трогаются.

Проверяется: парсинг каждого сайта, отправка только сегодняшних вакансий, отсутствие дублей (в том числе между вкладками и после перезапуска сервера), обрывы связи и ошибки Telegram, кнопки и счётчик непрочитанных, вкл/выкл из бота и попапа, тест-режим, безопасный режим.

## Структура

```
extension/
  manifest.json     права и сайты
  background.js     таймер, перезагрузка вкладок, лог, значок
  extract.js        парсер вакансий (выполняется на странице)
  popup.html/.js    окно расширения
server/
  server.js         HTTP API для расширения + Telegram-бот
  chat-id.js        npm run chat-id
tests/
  e2e.mjs           сквозной тест
  lib.mjs           загрузка снимков, генерация «новых» вакансий
  check-inject.mjs  быстрая проверка парсера без браузера
  fixtures/         сохранённые страницы для тестов
data/               (не в git) state.json, снимки, отладочные дампы
```
